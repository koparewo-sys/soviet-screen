СОВЕТСКИЙ ЭКРАН — версия с VK Видео и Rutube

Запуск: распакуйте архив и откройте index.html в браузере.

Обновление опубликованного сайта:
1. Загрузите содержимое папки в существующий GitHub-репозиторий soviet-screen.
2. Подтвердите замену старых файлов.
3. GitHub Pages обновит сайт автоматически после публикации.

На странице каждого фильма есть отдельные кнопки поиска трейлера в VK Видео и Rutube. Кнопки открывают поиск по названию и году фильма. Прямое встраивание плеера не добавлено, поскольку для него нужны проверенные ссылки конкретных видео и разрешение на встраивание.
